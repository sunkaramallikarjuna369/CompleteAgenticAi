What is RAG?

RAG combines an LLM with a retrieval system. Instead of relying on training data alone, the LLM retrieves relevant documents at inference time and uses them to generate grounded responses.

User Query -> Embed -> Vector Search -> Top-K Documents -> Augment Prompt -> LLM -> Grounded Response

Why RAG?

Up-to-date

Access info beyond training cutoff

Grounded

Reduce hallucination with source docs

No Fine-tuning

Just update the knowledge base

Private

Data stays in your infrastructure

RAG Components

Documents -> Loader -> Splitter -> Embedder -> Vector Store | User Query -> Embedder -> Vector Search -> Top-K Chunks -> LLM Prompt -> Response

For Agentic AI

RAG is THE primary way agents access domain knowledge. Every enterprise agent uses RAG.
