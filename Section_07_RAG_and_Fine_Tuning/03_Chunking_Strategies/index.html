Why Chunking Matters

Documents must be split into chunks for embedding. The chunking strategy dramatically affects RAG quality.

Strategies

Fixed Size

Split every N tokens with overlap. Simple but may break mid-sentence.

Recursive

Try paragraphs first, then sentences, then characters. Most popular.

Semantic

Split at topic boundaries using embedding similarity.

Document-Aware

Respect headers, sections, tables. Best for structured docs.

Key Parameters

ParameterRangeEffect
Chunk size256-1024 tokensLarger = more context, less precise
Overlap10-20%Prevents losing context at boundaries
Top-K3-10More chunks = more context, higher cost
