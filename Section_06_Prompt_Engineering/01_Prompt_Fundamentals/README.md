# Prompt Fundamentals

## What is a Prompt?
The input text you provide to an LLM. The quality of your prompt directly determines the quality of the output.

## Prompt Structure
1. **Role/Context**: Who should the LLM be?
2. **Task**: What should it do?
3. **Constraints**: Rules and limitations
4. **Examples**: Demonstrate expected output
5. **Output Format**: How to structure the response

## Best Practices
- Be specific and unambiguous
- Provide context and examples
- Break complex tasks into steps
- Specify output format explicitly
- Iterate and refine

## Zero-Shot vs Few-Shot
- Zero-shot: No examples, just instructions
- One-shot: One example
- Few-shot: 2-5 examples

## For Agentic AI
- Prompts define agent behavior, personality, and capabilities
- System prompts are the "DNA" of an agent
