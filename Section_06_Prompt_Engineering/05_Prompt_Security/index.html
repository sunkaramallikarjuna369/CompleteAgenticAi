Security Threats

Prompt Injection

Malicious instructions hidden in user input that override the system prompt.

Jailbreaking

Creative prompting to bypass safety guardrails.

Data Exfiltration

Tricking the model into revealing system prompts or sensitive data.

Defenses

Defense-in-Depth for Agents

  • Input sanitization and validation
  • Output filtering and monitoring
  • Action validation before execution
  • Content safety classifiers
  • Rate limiting and anomaly detection
  • Guardrail frameworks: NeMo Guardrails, Guardrails AI

Critical for Agentic AI

Agents with tool access are HIGH RISK targets. A prompt injection could cause an agent to execute harmful actions, delete files, or exfiltrate data.
