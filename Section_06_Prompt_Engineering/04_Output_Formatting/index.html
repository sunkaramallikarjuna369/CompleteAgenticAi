Why Structured Output?

Agents must produce machine-readable output for tool calls. Free-form text is unreliable for programmatic use.

Function Calling

JSON { "name": "search_web", "arguments": { "query": "weather in New York City", "num_results": 5 } }

How Agents Use Tools

The LLM generates a structured function call. The runtime executes it and returns results. The LLM processes results and decides next action.
