# System Prompts

## What is a System Prompt?
The hidden instruction that defines an agent's behavior, personality, capabilities, and constraints.

## Key Components
1. **Identity**: Who/what the agent is
2. **Capabilities**: What it can do (tools, APIs)
3. **Constraints**: What it must NOT do
4. **Behavior**: Tone, style, approach
5. **Tool Definitions**: Available tools and their schemas
6. **Examples**: Demonstration of expected behavior

## Best Practices
- Be explicit about what the agent should and shouldn't do
- Define tool usage patterns clearly
- Include error handling instructions
- Specify output formats
- Add safety guardrails

## For Agentic AI
- System prompts are the MOST important part of agent design
- They define the agent's personality, capabilities, and safety
