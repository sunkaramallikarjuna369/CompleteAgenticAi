The DNA of an Agent

System prompts are the most important part of agent design. They define everything: identity, capabilities, constraints, and behavior.

System Prompt Components

Identity

"You are a helpful coding assistant that specializes in Python."

Capabilities

"You can search the web, run code, and read files."

Constraints

"Never execute destructive commands. Always ask before deleting."

Tools

JSON schemas defining available tools and parameters.
