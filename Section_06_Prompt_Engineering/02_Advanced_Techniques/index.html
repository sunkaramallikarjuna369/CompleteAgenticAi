Chain-of-Thought (CoT)

The Power of "Think Step by Step"

Adding "Let's think step by step" to a prompt can dramatically improve reasoning accuracy. The model shows its work, catching errors along the way.

ReAct: Reasoning + Acting

Thought: I need to find the current weather in NYC Action: search("weather in New York City") Observation: Currently 72F, sunny, humidity 45% Thought: I have the information, I can now respond Answer: It is currently 72F and sunny in NYC with 45% humidity

THE Pattern for Agents

ReAct is the foundational prompting pattern for AI agents. It interleaves reasoning (thoughts) with actions (tool calls), enabling agents to interact with the world while maintaining a chain of reasoning.
