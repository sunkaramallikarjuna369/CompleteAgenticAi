# MLOps Fundamentals

## ML Lifecycle
Experiment -> Train -> Evaluate -> Package -> Deploy -> Monitor -> Retrain

## Key Components
- **Model Versioning**: MLflow, DVC
- **CI/CD for ML**: GitHub Actions, Kubeflow
- **Model Serving**: TorchServe, Triton, vLLM
- **Monitoring**: Data drift, model drift (Evidently, Prometheus)
- **Feature Store**: Feast, Tecton

## LLMOps
- Prompt management and versioning
- Token usage monitoring
- Guardrails and safety checks
- RAG pipeline management
- Tools: LangSmith, Helicone, Langfuse

## For Agentic AI
- Agents need robust deployment, monitoring, updating
- Observability (logging every step) is essential
- Cost management is crucial
