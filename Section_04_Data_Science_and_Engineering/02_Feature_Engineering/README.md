# Feature Engineering

## Types
### Numerical: Scaling, log transform, polynomial, binning
### Categorical: One-hot, label encoding, target encoding, embeddings
### Text: TF-IDF, Word2Vec, BERT embeddings, sentence embeddings
### Time: Cyclical encoding, lag features, rolling stats

## Feature Selection
- Filter: Correlation, mutual information
- Wrapper: Forward/backward selection
- Embedded: L1 regularization, tree importance

## For Agentic AI
- Embeddings are THE most important feature for agents
- Prompt engineering IS feature engineering for LLMs
