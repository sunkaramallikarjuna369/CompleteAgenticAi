# Model Training & Evaluation

## Training Strategies
- Hyperparameter tuning: Grid, Random, Bayesian (Optuna)
- Learning rate schedulers: Cosine annealing, warmup+decay
- Early stopping, gradient clipping, checkpointing

## Evaluation Metrics
### Classification: Accuracy, Precision, Recall, F1, AUC-ROC
### Regression: MSE, RMSE, MAE, R-squared
### Agent-Specific: Task completion rate, tool call accuracy, response quality, latency, cost

## Experiment Tracking
- MLflow, Weights & Biases, Neptune, TensorBoard

## For Agentic AI
- Agent evaluation needs both automated and human metrics
- A/B testing is crucial for comparing agent versions
