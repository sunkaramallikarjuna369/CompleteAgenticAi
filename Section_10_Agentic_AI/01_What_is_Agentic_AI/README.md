# What is Agentic AI?

## Definition
Agentic AI refers to AI systems that can autonomously pursue goals, make decisions, take actions, and adapt based on feedback - with minimal human intervention.

## Key Characteristics
1. **Autonomy**: Operates independently toward goals
2. **Goal-Directed**: Pursues specific objectives
3. **Tool Use**: Interacts with external systems
4. **Planning**: Decomposes tasks and creates plans
5. **Memory**: Maintains context across interactions
6. **Reasoning**: Thinks through problems step by step
7. **Adaptation**: Learns from feedback and adjusts
8. **Self-Reflection**: Evaluates own performance

## Agentic AI vs Traditional AI
| Aspect | Traditional AI | Agentic AI |
|--------|---------------|------------|
| Interaction | Single request-response | Multi-step autonomous |
| Decision making | Human-directed | Agent-directed |
| Tool use | None | Extensive |
| Memory | Stateless | Stateful |
| Planning | None | Task decomposition |
| Adaptation | Static | Dynamic |

## Levels of Agency
1. **L1 - Simple Chat**: Basic Q&A, no tools
2. **L2 - Tool Use**: Can call functions/APIs
3. **L3 - Planning**: Can decompose and plan tasks
4. **L4 - Multi-step**: Autonomous multi-step execution
5. **L5 - Multi-agent**: Coordinates with other agents
6. **L6 - Fully Autonomous**: Self-improving, minimal human oversight

## For Architects
- Agentic AI is the next evolution of enterprise AI
- Understanding levels of agency helps scope projects
- Start with L2-L3 and evolve toward higher levels
