Architecture Patterns

Single Agent

One LLM with tools. Simplest. Good starting point.

Router

Routes queries to specialized sub-agents.

Pipeline

Sequential processing stages.

Supervisor

Oversees and coordinates worker agents.

For Architects

Start simple (single agent), add complexity only when needed. Always include guardrails and observability from day one.
