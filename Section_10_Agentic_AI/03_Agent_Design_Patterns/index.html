Core Patterns

ReAct

Thought -> Action -> Observation -> Thought -> ... The default agent pattern.

Plan-and-Execute

Create full plan first, then execute steps sequentially.

Reflection

Generate -> Evaluate -> Improve -> Iterate until quality threshold.

Human-in-the-Loop

Request human approval for critical or irreversible decisions.

ReAct in Detail

Thought: I need to find the current stock price of AAPL Action: search("AAPL stock price today") Observation: AAPL is trading at $185.50 Thought: I have the price, now I can calculate the portfolio value Action: calculate(shares=100, price=185.50) Observation: Portfolio value = $18,550 Answer: Your 100 shares of AAPL are worth $18,550
