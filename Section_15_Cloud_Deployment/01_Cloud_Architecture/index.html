Key Design Decisions

Managed vs Self-hosted

API (faster start) vs Self-hosted (cost control, privacy)

Stateful vs Stateless

State in service (simpler) vs external store (scalable)

Sync vs Async

Real-time (chat) vs background (batch processing)

Single vs Multi-region

Simple vs low latency globally

For Architects

Start with managed LLM APIs for faster time-to-market. Design for horizontal scaling from day one. Add self-hosted models later for cost or privacy.
