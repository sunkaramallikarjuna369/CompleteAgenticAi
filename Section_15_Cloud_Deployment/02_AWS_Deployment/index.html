Key AWS Services

Amazon Bedrock

Managed LLMs (Claude, Llama, Titan). Serverless, with built-in RAG and agents.

SageMaker

Full ML lifecycle. Training, fine-tuning, hosting.

Lambda

Serverless compute for tools and event processing.

ECS/EKS

Container orchestration for agent services.

AWS Agent Architecture

API Gateway -> Lambda/ECS (Agent Orchestration) -> Bedrock (LLM) | | OpenSearch (RAG) S3 (Documents) | DynamoDB (State) CloudWatch (Monitoring)

For Architects

Bedrock + OpenSearch + Lambda = fastest path to production agents on AWS. Serverless, scalable, and cost-effective.
