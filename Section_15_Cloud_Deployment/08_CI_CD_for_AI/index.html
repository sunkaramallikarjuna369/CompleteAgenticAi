Deployment Strategies

Blue-Green

Two environments, instant switch. Safe rollback.

Canary

Gradual rollout: 1% -> 10% -> 50% -> 100%

Feature Flags

Toggle capabilities without redeploying.

Shadow Mode

Run new version alongside old, compare outputs.

For Architects

Treat agents like production services. Include AI-specific tests (prompt eval, tool tests). Use canary deployments for safety. Monitor closely after each release.
