# Multimodal Models

## What Are Multimodal Models?
Models that process multiple types of input: text + images + audio + video.

## Key Models
- **GPT-4V/4o**: Text + images + audio
- **Gemini**: Text + images + audio + video
- **Claude 3.5**: Text + images
- **CLIP**: Text-image alignment (OpenAI)
- **LLaVA**: Open-source vision-language

## How They Work
1. Vision Encoder: Process image into embeddings
2. Projection: Align visual embeddings with text space
3. LLM: Process combined text+visual tokens
4. Output: Generate text response about the image

## Capabilities
- Image understanding and description
- Visual question answering
- Document/chart analysis
- Screenshot understanding
- Video understanding

## For Agentic AI
- Multimodal agents can see and understand visual content
- Screen-based agents (computer use) require vision
- Document processing agents use vision for PDFs, charts
