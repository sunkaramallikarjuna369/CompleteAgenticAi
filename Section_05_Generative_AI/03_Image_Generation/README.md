# Image Generation

## Diffusion Models
Add noise to images gradually, then learn to reverse the process.
1. Forward: Image -> Noise (add noise step by step)
2. Reverse: Noise -> Image (denoise step by step)

## Key Models
- **DALL-E 3**: OpenAI, text-to-image
- **Stable Diffusion**: Open-source, customizable
- **Midjourney**: High-quality artistic generation
- **Imagen**: Google, photorealistic

## GANs (Generative Adversarial Networks)
- Generator creates, Discriminator evaluates
- Replaced by diffusion models for most tasks

## For Agentic AI
- Multimodal agents can generate images as tool output
- Vision understanding enables agents to process screenshots, diagrams
