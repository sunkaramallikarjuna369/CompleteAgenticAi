# Code Generation

## Code LLMs
LLMs specifically trained on code repositories.

## Key Models
| Model | Provider | Languages | Use Case |
|-------|----------|-----------|----------|
| GPT-4 | OpenAI | All major | General coding |
| Claude 3.5 | Anthropic | All major | Long context coding |
| Codex | OpenAI | Python-focused | GitHub Copilot |
| CodeLlama | Meta | Multiple | Open-source |
| StarCoder | BigCode | 80+ languages | Open-source |

## Capabilities
- Code completion and generation
- Bug detection and fixing
- Code explanation and documentation
- Test generation
- Code translation between languages
- Refactoring suggestions

## For Agentic AI
- Code generation IS a core agent capability
- Agents use code generation for tool creation
- Understanding code LLMs helps design coding agents
