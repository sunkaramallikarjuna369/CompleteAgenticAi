Communication Patterns

Message Passing

Structured messages between agents. Most common.

Shared State

Read/write to shared store. Simple but needs coordination.

Event-Driven

Publish/subscribe to events. Loosely coupled.

Direct Calls

Invoke capabilities directly. Tightly coupled but fast.
