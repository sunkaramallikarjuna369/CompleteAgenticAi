# Section 02: Key Technologies

## Overview

The key technologies that power modern AI systems span multiple domains — from understanding human language to interpreting visual data. These technologies are the building blocks that AI agents use to perceive and interact with the world.

| [04_Transfer_Learning](./04_Transfer_Learning/) | Transfer Learning | Pre-training, Fine-tuning, Domain Adaptation |

## Why These Technologies Matter for Agentic AI

AI Agents need to **perceive** the world through multiple modalities:
- **NLP** enables agents to understand and generate human language
- **Computer Vision** lets agents process images and visual information
- **Speech Recognition** allows voice-based interaction
- **Transfer Learning** is how we adapt foundation models for specific agent tasks
