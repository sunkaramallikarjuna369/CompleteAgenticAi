Speech Technologies for Agents

ASR (Speech-to-Text)

Input

Converts spoken language into text. Enables voice commands and dictation.

Best Model: OpenAI Whisper — multilingual, robust, open-source

TTS (Text-to-Speech)

Output

Generates natural-sounding speech from text. Creates voice responses.

Best Model: ElevenLabs — ultra-realistic voice synthesis

Speaker Diarization

Analysis

Identifies who spoke when in multi-speaker audio. Critical for meeting agents.

Best Tool: pyannote.audio — open-source diarization

Voice Agent Architecture

User Speaks → Microphone → ASR (Whisper) → Text ↓ ┌─────────────────────┐ │ LLM Agent Brain │ │ - Understand intent │ │ - Call tools/APIs │ │ - Generate response │ └─────────┬───────────┘ ↓ Speaker ← Audio Output ← TTS (ElevenLabs) ← Response Text

Latency is Critical

Voice conversations feel natural only if the response comes within ~500ms. Every component (ASR → LLM → TTS) adds latency. Use streaming ASR, fast LLM inference, and streaming TTS to keep the experience smooth.

Code Example: Speech-to-Text with Whisper

Python import whisper # Load Whisper model model = whisper.load_model("base") # Transcribe audio file result = model.transcribe("meeting_recording.mp3") print(result["text"]) # With language detection print(f"Detected language: {result['language']}") # For real-time streaming, use faster-whisper from faster_whisper import WhisperModel model = WhisperModel("base", device="cuda") segments, info = model.transcribe("audio.mp3") for segment in segments: print(f"[{segment.start:.2f}s → {segment.end:.2f}s] {segment.text}")
