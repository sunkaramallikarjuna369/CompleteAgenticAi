# Planning & Reasoning

## Task Decomposition
Breaking complex tasks into manageable subtasks.

## Planning Strategies
- **Sequential**: Step-by-step execution
- **Hierarchical**: High-level plan with sub-plans
- **Iterative**: Plan, execute, observe, replan
- **Parallel**: Execute independent subtasks simultaneously

## Reasoning Techniques
- Chain-of-Thought: Step-by-step reasoning
- Tree of Thought: Explore multiple reasoning paths
- ReAct: Interleave reasoning with actions
- Reflection: Evaluate and improve reasoning

## For Agentic AI
- Planning is what separates simple agents from sophisticated ones
- The best agents combine multiple planning strategies
