Task Decomposition

Complex tasks must be broken into manageable subtasks. This is the foundation of agent planning.

Complex Task: "Build a web app with user auth" -> Subtask 1: Set up project structure -> Subtask 2: Create database schema -> Subtask 3: Implement auth endpoints -> Subtask 4: Build frontend forms -> Subtask 5: Test and deploy

Planning Strategies

Sequential

Step-by-step. Simple but slow.

Hierarchical

High-level plan with sub-plans. Better for complex tasks.

Iterative

Plan, execute, observe, replan. Adapts to results.

Parallel

Independent subtasks run simultaneously. Faster.
