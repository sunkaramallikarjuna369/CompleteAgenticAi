From Chatbot to Agent

Tool use transforms a chatbot into an agent. It's the ability to take actions in the real world - search, execute code, call APIs, manage files.

How It Works

1. Define tools: {name, description, parameters (JSON schema)} 2. User asks a question 3. LLM decides: "I need to use the search tool" 4. LLM generates: {"name": "search", "args": {"query": "..."}} 5. Runtime executes the tool call 6. Results returned to LLM 7. LLM generates final response using results

Tool Types

Search

Web search, knowledge base, vector DB

Code Execution

Python, JavaScript, SQL, shell

APIs

REST, GraphQL, databases

Browser

Navigate, click, type, screenshot

Files

Read, write, edit, search

Communication

Email, Slack, notifications

The Defining Capability

Tool use IS what makes an agent an agent. The quality of tool definitions directly affects agent performance.
