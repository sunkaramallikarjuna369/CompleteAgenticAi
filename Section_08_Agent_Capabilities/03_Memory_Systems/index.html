Agent Memory Types

Working Memory

Current conversation context. Limited by context window (128K tokens).

Long-term Memory

Persistent across conversations. Vector DBs, key-value stores.

Episodic Memory

Past experiences and interactions. Learn from history.

Semantic Memory

Facts and knowledge. RAG knowledge bases.

Procedural Memory

How to do things. Tools, workflows, learned procedures.

For Agentic AI

Memory makes agents persistent and personalized. The best agents combine all memory types for rich, contextual interactions.
