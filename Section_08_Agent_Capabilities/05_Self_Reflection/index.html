Self-Reflection

The ability to evaluate own outputs, detect errors, and improve. This is what separates autonomous agents from simple chatbots.

Techniques

Reflexion

Reflect on past actions to improve future behavior.

Self-Consistency

Generate multiple solutions, select the best.

Critic Models

Separate model evaluates output quality.

Error Recovery

Detect failures, retry with different approaches.

For Agentic AI

Self-reflection makes agents truly autonomous. The best agents learn from mistakes and improve over time.
