# Graph Neural Networks (GNNs)

## What Are GNNs?
Neural networks that operate on graph-structured data. They learn node representations by aggregating information from neighbors.

## Key Architectures
### GCN (Graph Convolutional Network)
Convolve over node neighborhoods. Each layer aggregates 1-hop neighbors.

### GAT (Graph Attention Network)
Use attention mechanisms to weight neighbor contributions differently.

### GraphSAGE
Sample and aggregate neighbors for scalable learning.

### Graph Transformers
Apply transformer attention to graph nodes. State-of-the-art performance.

## Applications
- Social network analysis
- Molecular property prediction
- Recommendation systems
- Fraud detection
- Knowledge graph completion

## For Agentic AI
- GNNs power graph-based reasoning in agents
- Knowledge graph completion helps agents discover new relationships
- Graph attention helps agents focus on relevant connections
