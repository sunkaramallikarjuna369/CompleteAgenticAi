# Haystack

## Overview
An end-to-end framework by deepset for building production-ready NLP and RAG pipelines.

## Key Features
- Pipeline-based architecture
- Multiple retriever types (BM25, dense, hybrid)
- Document stores (Elasticsearch, Weaviate, Pinecone)
- Agent capabilities with tool use
- Evaluation tools

## For Agentic AI
- Production-ready RAG pipelines
- Flexible pipeline composition
