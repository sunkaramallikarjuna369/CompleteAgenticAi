LlamaIndex

The data framework for LLM applications. Specializes in connecting LLMs with external data through advanced RAG.

Key Features

  • 100+ data connectors (PDFs, databases, APIs, web)
  • Advanced indexing (tree, keyword, vector, knowledge graph)
  • Query engines with routing and composition
  • Built-in agent framework
  • Evaluation and optimization tools
