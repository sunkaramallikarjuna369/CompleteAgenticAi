# LlamaIndex

## Overview
A data framework that makes it easy to connect LLMs with external data. Specializes in RAG and data-augmented generation.

## Key Features
- Data connectors (100+ sources)
- Advanced indexing strategies
- Query engines and chat engines
- Agent framework with tool use
- Evaluation tools

## For Agentic AI
- Best-in-class RAG capabilities
- Excellent for data-heavy agent applications
