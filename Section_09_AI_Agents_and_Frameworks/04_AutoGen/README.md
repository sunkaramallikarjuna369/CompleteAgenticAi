# AutoGen

## Overview
Microsoft's framework for building multi-agent systems through conversations. Agents communicate via messages.

## Key Features
- Conversable agents with different capabilities
- Human-in-the-loop support
- Code execution integration
- Group chat for multi-agent collaboration
- Flexible conversation patterns

## Agent Types
- AssistantAgent: LLM-powered agent
- UserProxyAgent: Represents human, can execute code
- GroupChatManager: Orchestrates multi-agent conversations

## For Agentic AI
- AutoGen excels at conversational multi-agent patterns
- Strong code execution and human-in-the-loop support
