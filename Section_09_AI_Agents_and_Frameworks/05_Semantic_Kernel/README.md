# Semantic Kernel

## Overview
Microsoft's open-source SDK for integrating AI into applications. Supports C#, Python, and Java.

## Key Concepts
- **Kernel**: Central orchestrator
- **Plugins**: Collections of functions (native + semantic)
- **Planners**: Automatically create execution plans
- **Memory**: Built-in semantic memory
- **Connectors**: Integration with Azure, OpenAI, etc.

## For Agentic AI
- Enterprise-grade AI orchestration
- Strong Azure and Microsoft ecosystem integration
