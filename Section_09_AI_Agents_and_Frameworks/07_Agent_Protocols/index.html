Agent Communication Standards

Standards and protocols that enable agents to communicate with tools, data, and each other.

Key Protocols

MCP (Model Context Protocol)

Anthropic's protocol for connecting models with external data and tools. Open standard.

A2A (Agent-to-Agent)

Google's protocol for agent discovery and inter-agent communication.

Function Calling

OpenAI's standard for structured tool calls. Widely adopted.

OpenAPI/Swagger

API description standard. Agents can read and use APIs automatically.

The Future

MCP and A2A are shaping how agents will interoperate in the future. Understanding these protocols is essential for building agent ecosystems.
