# Agent Protocols & Standards

## Model Context Protocol (MCP)
Anthropic's open protocol for connecting AI models with external data and tools. Standardizes how agents access context.

## Agent-to-Agent (A2A)
Google's protocol for agent-to-agent communication. Enables agents to discover and interact with each other.

## OpenAI Function Calling
Standard for LLMs to generate structured tool calls. Widely adopted across providers.

## Tool Use Standards
- JSON Schema for tool definitions
- OpenAPI/Swagger for API descriptions
- GraphQL for flexible data queries

## For Agentic AI
- Standards enable interoperability between agents
- MCP and A2A are shaping the future of agent ecosystems
