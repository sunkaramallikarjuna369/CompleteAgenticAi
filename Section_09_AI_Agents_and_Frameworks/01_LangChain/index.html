Key Abstractions

  • Chat Models: Unified interface to GPT-4, Claude, Llama
  • Chains: Compose LLM calls with other operations
  • Agents: LLMs that decide which tools to use
  • Tools: Functions the agent can call
  • Memory: Conversation and persistent memory
  • Retrievers: RAG retrieval interfaces
