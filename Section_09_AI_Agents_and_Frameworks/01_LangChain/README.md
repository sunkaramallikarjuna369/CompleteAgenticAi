# LangChain

## Overview
The most popular framework for building LLM applications. Provides abstractions for chains, agents, tools, memory, and retrieval.

## Key Components
- **LLMs/Chat Models**: Unified interface to OpenAI, Anthropic, etc.
- **Chains**: Compose LLM calls with other operations
- **Agents**: LLMs that decide which tools to use
- **Tools**: Functions the agent can call
- **Memory**: Conversation and long-term memory
- **Retrievers**: RAG retrieval interfaces

## LangGraph
LangChain's framework for building stateful, multi-step agent workflows as graphs.

## LangSmith
Observability platform for debugging, testing, and monitoring LLM applications.

## For Agentic AI
- LangChain is the most widely used agent framework
- LangGraph enables complex multi-step agent workflows
