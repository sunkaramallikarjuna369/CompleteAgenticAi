What is a Neural Network?

A neural network is a computational model inspired by the human brain. It consists of layers of interconnected nodes (neurons) that process information and learn patterns from data through training.

A Single Neuron

Each neuron computes: output = activation(w1*x1 + w2*x2 + ... + wn*xn + bias)

The weights (w) and bias are LEARNED during training. The activation function adds non-linearity, allowing the network to model complex patterns.

Activation Functions

ReLU (Rectified Linear Unit)

f(x) = max(0, x)

The default choice for hidden layers. Simple, fast, avoids vanishing gradients. Returns 0 for negatives, x for positives.

Sigmoid

f(x) = 1 / (1 + e^-x)

Squashes output to (0, 1). Used for binary classification outputs. Prone to vanishing gradients in deep networks.

Softmax

f(xi) = e^xi / sum(e^xj)

Converts logits to probabilities that sum to 1. Used for multi-class classification output layers.

GELU

f(x) = x * Phi(x)

Used in Transformers (GPT, BERT). Smooth approximation of ReLU. Powers modern LLMs and AI agents.

Backpropagation — How Networks Learn

FORWARD PASS (make prediction): Input → Layer 1 → Layer 2 → ... → Output → Compare with truth → Loss BACKWARD PASS (learn from error): Loss → Calculate gradients → Update weights → Reduce error (chain rule) (gradient descent)

This cycle repeats thousands to millions of times. Each iteration makes the weights slightly better at producing correct outputs.

Vanishing & Exploding Gradients

Vanishing: Gradients become tiny in early layers — they stop learning. Solution: ReLU, skip connections (ResNet), proper initialization.

Exploding: Gradients become enormous — training diverges. Solution: Gradient clipping, batch normalization, lower learning rate.

Regularization — Preventing Overfitting

Dropout

Randomly "turn off" neurons during training (e.g., 20%). Forces the network to learn redundant representations. At inference, all neurons are active.

Batch Normalization

Normalize layer inputs to zero mean and unit variance. Stabilizes training, allows higher learning rates, acts as mild regularization.

Weight Decay (L2)

Add penalty for large weights to the loss function. Encourages simpler models that generalize better.

Early Stopping

Monitor validation loss. Stop training when it starts increasing (the model is starting to overfit to training data).
