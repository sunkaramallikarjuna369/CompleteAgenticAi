Attention Is All You Need

Attention lets models focus on relevant input parts. When you read "it" in "The cat sat because it was tired", you attend to "cat". Self-attention does this mathematically.

Types of Attention

Self-Attention

Each token attends to ALL others. Used in encoders.

Causal Attention

Only attend to PREVIOUS tokens. Used in GPT, Claude.

Cross-Attention

Attend across sequences. Used in translation.

Multi-Head

Multiple parallel attention ops capturing different patterns.
