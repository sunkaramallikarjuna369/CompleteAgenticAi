How Convolution Works

A small filter (kernel) slides across the input image, computing a dot product at each position. The result is a feature map that highlights where the pattern was detected.

CNN Architecture

Input Image → [Conv + ReLU + Pool] → [Conv + ReLU + Pool] → Flatten → FC → Output (3x224x224) (32 filters) (64 filters) (vector) (classes) Feature Hierarchy: Layer 1: Edges, gradients Layer 2: Textures, corners Layer 3: Object parts (eyes, wheels) Layer 4: Complete objects (faces, cars)

Convolutional Layer

Applies learned filters to detect features. Each filter produces one feature map. Parameters: kernel size, number of filters, stride, padding.

Pooling Layer

Reduces spatial dimensions. Max Pooling takes the maximum in each region. Provides translation invariance and reduces computation.

Fully Connected Layer

Standard neural network layers at the end. Combines all features for final classification decision.

ResNet's Skip Connections — The Most Important Innovation

ResNet introduced residual connections that let gradients flow directly through the network. This same idea is used in EVERY modern Transformer (GPT, BERT, Claude). Understanding ResNet helps you understand why Transformers work!

x ──→ Conv ──→ ReLU ──→ Conv ──→ (+) ──→ ReLU ──→ output | ↑ └────────── skip connection ───────┘ Output = F(x) + x (learn the RESIDUAL, not the full mapping)

Code Example: CNN with PyTorch

Python import torch.nn as nn class SimpleCNN(nn.Module): def __init__(self): super().__init__() self.features = nn.Sequential( nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2), ) self.classifier = nn.Sequential( nn.Flatten(), nn.Linear(64 * 56 * 56, 512), nn.ReLU(), nn.Dropout(0.5), nn.Linear(512, 10), ) def forward(self, x): x = self.features(x) return self.classifier(x)
