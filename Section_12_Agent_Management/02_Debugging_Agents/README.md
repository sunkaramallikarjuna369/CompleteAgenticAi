# Debugging Agents

## Common Issues
- Agent loops (repeating same action)
- Wrong tool selection
- Hallucinated tool arguments
- Context window overflow
- Prompt injection vulnerabilities
- Inconsistent behavior

## Debugging Techniques
- Trace analysis: Follow the full execution path
- Prompt inspection: Check what the LLM actually sees
- Tool call validation: Verify arguments and results
- Regression testing: Compare behavior across versions
- Replay: Re-run past interactions for debugging

## For Agentic AI
- Systematic debugging requires good observability
- Build regression test suites for critical agent behaviors
