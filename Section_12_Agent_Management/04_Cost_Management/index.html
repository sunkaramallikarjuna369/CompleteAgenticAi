Cost Drivers

Input Tokens

Prompt + context. RAG adds significant input tokens.

Output Tokens

Response length. Usually more expensive than input.

LLM Calls

Multi-step agents make many calls per task.

Model Choice

GPT-4 is 60x more expensive than GPT-3.5.

Optimization Strategies

  • Model Routing: Cheap model for simple tasks, expensive for complex (5-10x savings)
  • Caching: Cache common queries (semantic cache)
  • Prompt Optimization: Shorter prompts, fewer examples
  • Token Budgets: Set limits per task/user
  • Open-Source: Self-host for high-volume tasks
