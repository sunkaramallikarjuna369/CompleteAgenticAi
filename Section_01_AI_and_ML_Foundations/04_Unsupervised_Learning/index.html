What is Unsupervised Learning?

Unlike supervised learning, there are no labels. The algorithm explores the data and discovers structure, patterns, and relationships on its own.

Analogy

Imagine sorting a box of mixed coins from different countries. Nobody tells you which coins are which — you group them by size, color, and markings. That's unsupervised learning: finding structure without guidance.

Clustering Algorithms

K-Means

Most Popular

Partitions data into K clusters by minimizing distance to cluster centers (centroids).

  • Fast and scalable
  • Must choose K in advance
  • Assumes spherical clusters
  • Use Elbow Method to find optimal K

DBSCAN

Density-Based

Groups points in dense regions. Points in sparse regions are labeled as outliers.

  • No need to specify number of clusters
  • Handles arbitrary shapes
  • Built-in outlier detection
  • Struggles with varying density

Hierarchical

Tree-Based

Builds a dendrogram (tree) of nested clusters from individual points up to one cluster.

  • Visual and interpretable
  • No need to pre-specify K
  • Agglomerative (bottom-up) most common
  • Slow for large datasets: O(n^3)

Dimensionality Reduction

Reduces the number of features while preserving the most important information. Essential for visualization and preprocessing.

For Agentic AI

Vector embeddings — the backbone of RAG systems and semantic search — are essentially dimensionality reduction. Text is compressed from thousands of tokens into dense vectors where similar meanings are close together. This is how agents "understand" and retrieve relevant knowledge.

Anomaly Detection

Isolation Forest

Randomly partitions data. Anomalies are isolated in fewer steps than normal points. Fast and effective.

One-Class SVM

Learns a boundary around "normal" data. Points outside the boundary are flagged as anomalies.

Autoencoders

Neural network trained to reconstruct normal data. Anomalies produce high reconstruction error because the model hasn't learned their patterns.

Code Example: K-Means Clustering

Python from sklearn.cluster import KMeans from sklearn.datasets import make_blobs import matplotlib.pyplot as plt # Generate sample data X, _ = make_blobs(n_samples=300, centers=4, random_state=42) # Fit K-Means kmeans = KMeans(n_clusters=4, random_state=42) labels = kmeans.fit_predict(X) # Visualize plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis') plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], marker='X', s=200, c='red') plt.title('K-Means Clustering') plt.show()
