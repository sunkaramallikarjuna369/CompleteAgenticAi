How Splitting Works

At each node, the algorithm finds the feature and threshold that best separates the classes. Measured by Information Gain (entropy reduction) or Gini Impurity (probability of misclassification).

Preventing Overfitting

Pruning: Remove branches that don't significantly improve predictions. Max depth: Limit tree depth. Min samples: Require minimum samples per leaf.

Random Forest & Gradient Boosting

Random Forest (Bagging)

Train many trees independently on random data subsets. Combine via voting/averaging.

Tree 1 → Class A Tree 2 → Class B → Vote → Class A Tree 3 → Class A Tree 4 → Class A Tree 5 → Class B

Key advantage: Reduces variance (overfitting) through averaging

Gradient Boosting (Boosting)

Train trees sequentially. Each new tree corrects the errors of all previous trees.

Tree 1 → Errors ↓ focus on errors Tree 2 → Smaller Errors ↓ focus on remaining Tree 3 → Even Smaller Errors ↓ Final = Sum of all trees

Key advantage: Reduces bias (underfitting) through correction

XGBoost / LightGBM / CatBoost

These are optimized gradient boosting implementations. XGBoost dominates Kaggle competitions. LightGBM is faster for large datasets. CatBoost handles categorical features natively. For structured data, these often outperform deep learning!

SVM finds the hyperplane with the widest margin between classes. The kernel trick enables non-linear boundaries by mapping data to higher dimensions.

Kernel Functions

  • Linear: For linearly separable data
  • RBF (Radial Basis Function): Most versatile, handles complex boundaries
  • Polynomial: For polynomial decision boundaries
  • Sigmoid: Similar to neural network activation

Code Example: XGBoost vs Random Forest

Python from sklearn.ensemble import RandomForestClassifier from xgboost import XGBClassifier from sklearn.datasets import load_breast_cancer from sklearn.model_selection import cross_val_score X, y = load_breast_cancer(return_X_y=True) # Random Forest rf = RandomForestClassifier(n_estimators=100, random_state=42) rf_scores = cross_val_score(rf, X, y, cv=5) print(f"Random Forest: {rf_scores.mean():.4f}") # XGBoost xgb = XGBClassifier(n_estimators=100, random_state=42) xgb_scores = cross_val_score(xgb, X, y, cv=5) print(f"XGBoost: {xgb_scores.mean():.4f}")
