# Section 01: AI & ML Foundations

## Overview

Artificial Intelligence (AI) and Machine Learning (ML) form the bedrock of everything in the Agentic AI framework. Before you can build autonomous AI agents, you must deeply understand how machines learn from data, make predictions, and improve over time.

This section covers:
- What AI and ML actually are (and aren't)
- The three pillars of ML: Supervised, Unsupervised, and Reinforcement Learning
- Classical ML algorithms that still power many production systems
- How these foundations connect to the agent systems we'll build later

## Why This Matters for Agentic AI

```
AI/ML Foundations ──► Powers the "brain" of AI Agents
                 ──► Enables learning from environment feedback
                 ──► Drives decision-making capabilities
                 ──► Forms the basis for LLMs and Generative AI
```

Every AI agent, whether it's a simple chatbot or a complex multi-agent system orchestrating enterprise workflows, relies on machine learning at its core. Understanding these fundamentals will help you:

1. **Choose the right approach** for different agent tasks
2. **Debug and optimize** agent behavior
3. **Explain to stakeholders** why agents make certain decisions
4. **Design better agent architectures** that leverage the right ML paradigms

## Key Terminology

| Term | Definition |
|------|-----------|
| **Artificial Intelligence** | The broad field of creating machines that can perform tasks requiring human intelligence |
| **Machine Learning** | A subset of AI where systems learn from data without being explicitly programmed |
| **Deep Learning** | A subset of ML using neural networks with multiple layers |
| **Model** | A mathematical representation learned from data |
| **Training** | The process of teaching a model using data |
| **Inference** | Using a trained model to make predictions on new data |
| **Feature** | An individual measurable property of the data |
| **Label** | The target variable in supervised learning |
| **Hyperparameter** | Configuration settings that control the training process |
