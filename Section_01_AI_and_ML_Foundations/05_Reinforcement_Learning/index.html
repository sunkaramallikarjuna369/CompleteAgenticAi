The RL Framework

An agent learns by interacting with an environment. At each step, it observes the state, takes an action, receives a reward, and moves to the next state. The goal: maximize cumulative reward.

┌─────────┐ action (a) ┌─────────────┐ │ AGENT │ ────────────────► │ ENVIRONMENT │ │ │ │ │ │ Policy │ ◄──────────────── │ World, │ │ π(s)→a │ state(s), reward │ Physics, │ └─────────┘ (r) │ Rules │ └─────────────┘

Why RL is the Foundation of Agentic AI

Modern AI agents follow the exact same loop: observe (read context/state) → decide (choose action via LLM) → act (call tools/APIs) → receive feedback (results/errors) → improve. RL formalized this loop decades before LLM-based agents existed!

Exploration vs Exploitation

Exploration

Try new, unknown actions to potentially discover better strategies. Risk: waste time on bad options.

Agent parallel: Trying a different tool or approach for a task

Exploitation

Use known good actions to maximize immediate reward. Risk: miss better opportunities.

Agent parallel: Using a proven tool/method that worked before

Balance is Key

The epsilon-greedy strategy explores with probability epsilon (e.g., 10%) and exploits with probability 1 - epsilon (90%). Modern agents achieve this through temperature sampling in LLMs — higher temperature = more exploration.

Key Algorithms

Q-Learning

Value-Based

Learns the value of each state-action pair. The agent picks the action with the highest Q-value.

Bellman Equation: Q(s,a) = r + gamma * max Q(s',a')

Off-policy: Can learn from others' experience

Deep Q-Network (DQN)

Deep RL

Neural network approximates Q-function. DeepMind used this to master Atari games (2013).

Key innovations: Experience replay buffer, target network for stability

PPO (Proximal Policy Optimization)

Policy-Based

Most popular RL algorithm today. Directly optimizes the policy with stable updates. Used in RLHF for ChatGPT, Claude.

Key property: Clipped objective prevents too-large policy updates

Actor-Critic (A2C/A3C)

Hybrid

Combines value and policy methods. Actor chooses actions, Critic evaluates them. Best of both worlds.

Advantage: Measures how much better an action is vs average

RLHF — The Bridge to Modern AI Agents

Reinforcement Learning from Human Feedback is how we align LLMs with human preferences:

Step 1: Pre-train LLM on massive text corpus ↓ Step 2: Supervised Fine-Tuning on instruction-response pairs ↓ Step 3: Train a Reward Model from human preference comparisons ↓ Step 4: Optimize LLM policy using PPO against the Reward Model ↓ Result: A helpful, harmless, and honest AI assistant

Why RLHF Matters for Agentic AI

RLHF is what makes modern LLMs (GPT-4, Claude, Gemini) good at following instructions, using tools, and behaving safely. Without RLHF, the raw language model would just predict the next token — RLHF turns it into an agent that can follow goals.

Code Example: Simple Q-Learning

Python import numpy as np # Simple grid world Q-Learning n_states = 16 # 4x4 grid n_actions = 4 # up, down, left, right Q = np.zeros((n_states, n_actions)) # Hyperparameters alpha = 0.1 # learning rate gamma = 0.99 # discount factor epsilon = 0.1 # exploration rate def choose_action(state): if np.random.random() < epsilon: return np.random.randint(n_actions) # Explore return np.argmax(Q[state]) # Exploit def update_q(state, action, reward, next_state): best_next = np.max(Q[next_state]) Q[state, action] += alpha * ( reward + gamma * best_next - Q[state, action] ) # Training loop (conceptual) for episode in range(1000): state = 0 # start state done = False while not done: action = choose_action(state) # next_state, reward, done = env.step(action) # update_q(state, action, reward, next_state) # state = next_state break
