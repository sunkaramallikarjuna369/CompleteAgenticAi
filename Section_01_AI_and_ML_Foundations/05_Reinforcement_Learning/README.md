# Reinforcement Learning

## Overview

Reinforcement Learning (RL) is the ML paradigm most directly connected to Agentic AI. An agent learns to make decisions by taking actions in an environment and receiving rewards or penalties. The goal is to learn a policy that maximizes cumulative reward over time.

## Core Concepts

### The RL Framework
```
Agent ──(action)──► Environment
  ▲                      │
  │                      │
  └──(state, reward)─────┘
```

- **Agent**: The learner/decision-maker
- **Environment**: The world the agent interacts with
- **State (s)**: Current situation of the agent
- **Action (a)**: What the agent can do
- **Reward (r)**: Feedback signal — positive or negative
- **Policy (π)**: Strategy mapping states to actions
- **Value Function V(s)**: Expected cumulative reward from state s
- **Q-Function Q(s,a)**: Expected cumulative reward from taking action a in state s

### Key Concepts

**Exploration vs Exploitation**
- Exploration: Try new actions to discover potentially better rewards
- Exploitation: Use known actions that give good rewards
- Balance is critical — too much exploration wastes time, too much exploitation misses optimal solutions
- Epsilon-greedy strategy: Explore with probability ε, exploit with probability 1-ε

**Discount Factor (γ)**
- Controls how much the agent values future vs immediate rewards
- γ = 0: Only cares about immediate reward (myopic)
- γ = 1: Values all future rewards equally (far-sighted)
- Typically γ = 0.99 or 0.95

**Episode**: A complete sequence from start to terminal state
**Return**: Total discounted reward over an episode

## Key Algorithms

### Value-Based Methods
Learn the value of states or state-action pairs.

**Q-Learning**
- Learns Q(s,a) — the value of taking action a in state s
- Off-policy: Can learn from experience generated by a different policy
- Uses Bellman equation: Q(s,a) = r + γ * max Q(s',a')

**Deep Q-Network (DQN)**
- Uses neural network to approximate Q-function
- Breakthrough: DeepMind's Atari game player (2013)
- Key innovations: Experience replay, target networks

### Policy-Based Methods
Learn the policy directly without estimating values.

**REINFORCE**
- Monte Carlo policy gradient method
- Updates policy based on complete episode returns
- Simple but high variance

**Proximal Policy Optimization (PPO)**
- Most popular policy gradient method today
- Stable training with clipped objective function
- Used in ChatGPT's RLHF training

### Actor-Critic Methods
Combine value-based and policy-based approaches.

**A3C / A2C (Advantage Actor-Critic)**
- Actor: Learns the policy
- Critic: Learns the value function
- Advantage: How much better an action is compared to average

## RL in the Context of Agentic AI

| RL Concept | Agentic AI Equivalent |
|-----------|----------------------|
| Agent | AI Agent (LLM-based) |
| Environment | Tools, APIs, databases, users |
| State | Current context, conversation history, memory |
| Action | Tool calls, API requests, generating text |
| Reward | Task success, user satisfaction, goal completion |
| Policy | The agent's decision-making strategy |
| Episode | A complete task from start to finish |

## RLHF — Reinforcement Learning from Human Feedback

This is the bridge between RL and modern LLMs:

1. **Pre-train** LLM on large text corpus (supervised learning)
2. **Fine-tune** on instruction-response pairs (supervised)
3. **Train reward model** from human preference data
4. **Optimize policy** using PPO against the reward model

RLHF is what makes ChatGPT, Claude, and other assistants helpful, harmless, and honest.

## Summary

- RL teaches agents to make sequential decisions through trial and error
- It's the direct foundation for autonomous AI agents
- Modern AI agents combine RL principles with LLMs for powerful decision-making
- RLHF connects RL to the training of the LLMs that power today's agents
