How Supervised Learning Works

The algorithm learns a mapping from inputs (X) to outputs (y) using labeled examples. Once trained, it can predict outputs for new, unseen inputs.

Training: Input Features (X) + Known Labels (y) → Algorithm → Trained Model ↓ Inference: New Inputs (X_new) → Trained Model → Predictions (y_pred)

Analogy

Imagine studying for an exam with an answer key. You look at questions (features) and answers (labels), learn the patterns, then apply that knowledge to new questions you haven't seen before. That's supervised learning!

Classification vs Regression

Classification

Discrete Output

Predicts categories or classes.

  • Binary: Spam / Not Spam
  • Multi-class: Cat / Dog / Bird
  • Multi-label: Action AND Comedy

Algorithms: Logistic Regression, SVM, Random Forest, Neural Networks

Regression

Continuous Output

Predicts numerical values.

  • Price prediction: $350,000
  • Temperature: 72.5°F
  • Sales forecast: 1,247 units

Algorithms: Linear Regression, XGBoost, LightGBM, Neural Networks

Evaluation Metrics

For Classification

The Confusion Matrix

Predicted Positive Predicted Negative Actual Positive True Positive (TP) False Negative (FN) Actual Negative False Positive (FP) True Negative (TN) Precision = TP / (TP + FP) "Of all predicted positive, how many are correct?" Recall = TP / (TP + FN) "Of all actual positive, how many did we catch?" F1 Score = 2 * (P * R) / (P + R) "Harmonic mean — balances both"

When Accuracy Lies

If 99% of emails are not spam, a model that always predicts "not spam" gets 99% accuracy but catches zero spam! Always check Precision, Recall, and F1 for imbalanced datasets.

Connection to Agentic AI

Why This Matters for Agents

  • Intent Classification: Agents classify user intents to determine the right action
  • Entity Extraction: Supervised models extract key entities from text
  • Fine-tuning LLMs: Essentially supervised learning on instruction-response pairs
  • Agent Evaluation: We use precision, recall, and F1 to measure agent quality
  • Routing Decisions: Multi-agent systems use classifiers to route tasks to the right agent
